A make.fun entry for [Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) ($5 prize).

`main.py` writes exactly one line — a roast of a smart fridge that updated itself at 3 a.m. and now judges its owner's milk like a health inspector with a camera and a grudge — to `/output/entry.txt`. One line, no trailing newline, deterministic.

Run it with:

```sh
python3 main.py
```
